This guide walks you through creating a Kinotic App, defining an entity, syncing it with the server, and using the generated repository to read and write data.

## Prerequisites

- **Bun** -- Install from [https://bun.sh](https://bun.sh)
- **bunup** -- Used for building TypeScript packages

## Install the Kinotic CLI

```bash
bun install -g @kinotic-ai/kinotic-cli
```

Verify the installation:

```bash
kinotic --version
```

## Initialize a Project

Create a new directory for your application, create the entity and repository directories, and initialize the project with the CLI:

```bash
mkdir my-app && cd my-app
mkdir -p src/entities src/generated
kinotic init --application my-app --entities src/entities --repository src/generated
```

This creates a `.config/kinotic.config.ts` configuration file pointing the CLI at your entity and repository directories. Open it and set the `organizationId` field to your Kinotic organization id -- `kinotic sync` needs it to associate the project with your organization:

```typescript
import type { KinoticProjectConfig } from '@kinotic-ai/os-api'

const config: KinoticProjectConfig = {
  organizationId: "my-org",
  applicationId: "my-app",
  entitiesPaths: [
    {
      path: "src/entities",
      repositoryPath: "src/generated",
      mirrorFolderStructure: true
    }
  ],
  fileExtensionForImports: ".js",
  validate: false
}

export default config
```

## Install Dependencies

```bash
bun add @kinotic-ai/core @kinotic-ai/persistence
```

## Define an Entity

Create a file at `src/entities/Person.ts`:

```typescript
import { Entity, AutoGeneratedId, NotNull, Precision, PrecisionType, MultiTenancyType } from '@kinotic-ai/persistence'

@Entity(MultiTenancyType.NONE)
export class Person {
    @AutoGeneratedId
    id: string | null = null

    @NotNull
    firstName: string = ''

    @NotNull
    lastName: string = ''

    @Precision(PrecisionType.SHORT)
    age: number = 0
}
```

A few things to note:

- `@Entity(MultiTenancyType.NONE)` marks the class as a persisted entity with no multi-tenancy.
- `@AutoGeneratedId` tells the platform to generate an ID when one is not provided.
- `@NotNull` enforces that a field must have a value.
- `@Precision(PrecisionType.SHORT)` tells the platform this number is a short integer, which influences how it is stored and indexed.

## Sync with the Server

Log in to a running Kinotic OS instance, then push your entity definitions and generate the typed repository classes:

```bash
kinotic login --server http://localhost:58503
kinotic sync -p
```

The `-p` flag publishes the entity definitions so the platform creates the backing storage and registers the services. Sync also generates a complete repository class in the `src/generated` directory with methods for CRUD operations and querying.

## Use the Generated Repository

Create a file at `src/index.ts` to try it out:

```typescript
import { ConnectionInfo, Kinotic } from '@kinotic-ai/core'
import { PersistencePlugin } from '@kinotic-ai/persistence'
import { PersonRepository } from './generated/PersonRepository'

Kinotic.use(PersistencePlugin)

const connectionInfo = new ConnectionInfo()
connectionInfo.host = 'localhost'
connectionInfo.port = 58503

await Kinotic.connect(connectionInfo)

const personRepository = new PersonRepository()

// Create a person
const person = await personRepository.save({
    id: null,
    firstName: 'Jane',
    lastName: 'Doe',
    age: 28
})

console.log('Saved:', person)

// Find all people
const page = await personRepository.findAll({ page: 0, size: 10 })
console.log('People:', page.content)
```

Run it with Bun:

```bash
bun run src/index.ts
```

You should see the saved person printed to the console, followed by a page of results containing that person.
