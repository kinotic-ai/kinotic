An **organization** is the top-level home for everything you build on Kinotic. It owns its members, the identity providers they sign in with, and its [Apps](/apps/application-structure/overview).

Organization administrators manage the organization from **Organization settings** in the Kinotic portal.

## Organization setup

- **[Authentication providers](/organizations/authentication-providers)** -- let your members sign in to the portal with your company's identity provider, such as Okta.
- **[Apps](/apps/application-structure/overview)** -- build, publish, and deploy applications inside the organization.

For how organizations, users, and OIDC configurations work under the hood, see [Organization Management](/platform/organization-management).

## Sending feedback

**Send feedback** in the portal header opens a menu with **Report a bug** and **Request a feature**. Each opens GitHub's new-issue form on [kinotic-ai/kinotic](https://github.com/kinotic-ai/kinotic/issues) in a new tab, signed in with your GitHub account, so GitHub notifies you of comments and status changes on the issue.

The form starts with the route pattern of the portal page you were on, and a bug report also starts with your browser's user agent. Issues are public, so leave out secrets, personal data, and the names of your organization's applications and projects. Drag screenshots or logs into any multi-line field of the form to attach them.

An AI agent connected through [MCP](/platform/mcp-tools) reports a problem it hits while working with Kinotic through the Feedback Service Send tool, which files a bug report or feature request on [kinotic-ai/kinotic](https://github.com/kinotic-ai/kinotic/issues), labelled `bug` or `enhancement` and `feedback`, and returns the issue's link. The issue holds what the agent wrote and names its sender only as an AI agent by its client's name, a user, or a machine identity, never the organization or the person. An organization's agents can send ten an hour. The tool is offered only where the server has an [internal GitHub App](/platform/configuration#internal-github-app), as Kinotic Cloud does.
